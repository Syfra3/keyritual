# a2e guidance

Read and follow `.a2e/workflow.md` for the canonical workflow, builder and auditor roles. Humans approve the spec, select and run checks, review evidence and make sign-off decisions.

This generic adapter provides instructions only: it installs no hook or sandbox and does not enforce agent behavior, edit scope, test freezing or human approval. Use the human-managed workflow and do not claim caged enforcement. See the a2e installation guide for commands.
