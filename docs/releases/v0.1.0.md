# Keyritual v0.1.0 — stable source release notes

This release is intended as GitHub-generated source archives only, with no separate binary asset or marketplace action. The repository includes a bundled x86_64 Linux/glibc engine for the Quattro plugin.

## Changes

- Compact overlay controls, local command-shortcut preferences and an optional first-open global-hotkey consent flow.
- Rust engine and preferences updates; isolated installer, hotkey, bundle and consent tests.
- Safe local installer updates; existing unknown plugin contents are not silently replaced.

## Limitations

- Requires Omarchy Quattro/4.x for the overlay; bundled engine does not support ARM or incompatible older glibc.
- Current Quickshell pointer/keyboard controls and narrow viewports have not been verified live across displays/themes; accessibility remains unverified.
- The optional first-open shortcut script's effect on real user Hyprland configuration has not been verified live. Declining should leave it unchanged; accepting is an explicit user-local config operation.
- Clean-clone UI, History/Share and X compose external navigation/privacy need broader live checks. Screenshots in the README depict an earlier real UI, not proof of current controls.
- No marketplace listing or security review is implied by stable version numbering.
